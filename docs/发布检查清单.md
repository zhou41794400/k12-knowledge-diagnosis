# 发布检查清单

## 发布前必须确认

1. `python3 -m edu_tracker report` 可以执行。
2. `python3 -m edu_tracker materials` 可以执行。
3. `教育智能体/05-结果视图/` 已生成最新结果页。
4. `教育智能体/09-软著材料/生成稿/` 已生成最新软著材料稿。
5. `版本日志` 已记录本次变更。
6. `绩效报告` 已记录本次验证。
7. `releases/<版本>.md` 已生成或已准备。
8. 需要打标签时，仓库必须已有 `HEAD`。

## 发布前建议确认

- `pyproject.toml`、`README.md`、`CHANGELOG.md` 与当前功能一致。
- `docs/工程化说明.md` 与当前目录结构一致。
- `docs/日志归档规范.md` 与当前日志文件一致。
- 结果页中的中文外显没有混入过多内部术语。
- 可用 `make release VERSION=0.1.1` 生成发布说明。
- 可用 `make tag VERSION=0.1.1` 生成标签（前提是仓库已有提交）。

## 发布后建议动作

- 生成版本标签说明。
- 归档本次变更日志。
- 准备下一版需求和验证清单。
