# 工程化说明

## 项目形态

当前项目以本地优先为原则，核心代码通过 `edu_tracker` 命令行入口运行，结果输出到 Obsidian 目录和本地日志目录。

## 目录职责

- `edu_tracker/`：命令行入口层。
- `services/edu_tracker/`：核心分析、结果生成、软著材料生成逻辑。
- `教育智能体/`：知识体系、过程文档、结果视图和申报材料。
- `docs/`：工程化、发布和接续说明。

## 一键命令

- `make check`
- `make report`
- `make materials`
- `make all`
- `make bundle`

## 约束

1. 新功能必须同步更新 Obsidian 文档。
2. 用户可见文本优先中文。
3. 每次验证必须保留日志或生成稿。
4. 本地流程优先，正式外部集成后移。
