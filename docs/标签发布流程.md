# 标签发布流程

## 目标

- 让版本号、发布说明和 Git 标签一致。
- 在仓库存在 `HEAD` 的前提下，生成可追踪的轻量发布标签。

## 发布步骤

1. 生成发布说明。
2. 确认 `CHANGELOG.md` 和 Obsidian 版本日志一致。
3. 确认仓库已有至少一次提交。
4. 执行标签命令。
5. 记录标签结果到版本日志。

## 命令

```bash
make release VERSION=0.1.1
make tag VERSION=0.1.1
```

## 说明

- 标签名建议使用 `v0.1.1` 这种格式。
- 标签内容直接引用对应发布说明文件。
- 若仓库尚未提交，脚本会主动退出并提示先提交。
