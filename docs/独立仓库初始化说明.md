# 独立仓库初始化说明

## 目标

- 使用迁移包快速创建一个新的 GitHub 仓库初始目录。
- 保留工程化骨架、文档、结果页和软著材料生成稿。
- 不携带真实家庭日志和图片数据。

## 初始化命令

```bash
make bundle
sh scripts/init_independent_repo.sh /path/to/new-repo
```

## 初始化后检查

1. `make check`
2. `make report`
3. `make materials`
4. `make bundle`

## 备注

- 若需要指定旧迁移包，可追加第二个参数。
- 初始化后的目录可直接作为新仓库根目录。
