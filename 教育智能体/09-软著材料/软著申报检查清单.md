## 申报前建议补齐

1. 如果需要正式申报 PDF 格式，可运行 `make materials` 后使用 `python3 /tmp/gen_pdfs.py` 重新渲染 PDF 文件。
2. 后续版本变更后运行 `make materials` 重新生成所有材料。
3. 增加更多学科和年级的真实题目数据，使版本说明数据更充实。

```bash
cd /Users/mac/Documents/教育智能体
python3 -m edu_tracker materials
# 或
make materials
```
