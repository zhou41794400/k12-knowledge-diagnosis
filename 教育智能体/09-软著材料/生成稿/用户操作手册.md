# 用户操作手册

## 家长使用步骤

1. 录入试卷照片或手动题目。
2. 运行本地分析链路。
3. 查看结果视图中的短板和最近题目。
4. 根据复核标记补充答案或修正题目。

## 学生使用步骤

1. 打开学生周报。
2. 查看当前掌握情况和短板清单。
3. 按系统建议优先复习薄弱知识点。

## 本地命令

- `python3 -m edu_tracker manual ...`
- `python3 -m edu_tracker photo ...`
- `python3 -m edu_tracker report`
- `python3 -m edu_tracker materials`

## 注意事项

- 图片导入当前支持旁路文本验证，正式 OCR 仍需后续接入。
- 页面展示尽可能使用中文。
