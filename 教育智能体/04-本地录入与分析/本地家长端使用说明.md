# 本地家长端使用说明

## 启动

```bash
cd /Users/mac/Documents/教育智能体
make web
```

浏览器打开 `http://127.0.0.1:8765`。服务默认只绑定本机回环地址，不对局域网或公网开放。

## 家长可完成的操作

1. 手动输入学生编号、年级、题干、标准答案和学生作答。
2. 上传 PNG、JPG、WEBP 或 TIFF 图片，单张不超过 15MB。
3. 在待复核区修正 OCR 文本并确认。
4. 对未匹配或歧义题选择已发布知识点，确认对错后写入证据。
5. 对无需继续处理的任务仅关闭或放弃。
6. 查看家长端汇总报告。

## 安全边界

- 图片保存在本地 `教育智能体/logs/uploads/`，该目录不进入 Git。
- OCR 结果未确认前不更新掌握度。
- 人工复核证据标记为 `manual_review`，保留审计日志。
- 当前界面为本地试点版，不代表已完成公网发布、账号鉴权或多设备同步。
