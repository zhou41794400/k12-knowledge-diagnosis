# 新手快速上手

> [!tip] 5 分钟完成第一次体验
> 启动本地服务，手动录入一道题，再打开家长报告查看结果。首次使用建议先走手动录题，不要直接从整张试卷开始。

## 使用前须知

- 当前试点范围是**小学二至三年级数学**，运行时已发布 9 个知识点。
- 数据默认只保存在这台电脑，不上传公网。
- 学生编号建议使用 `s001`、`s002` 等匿名编号，不填写学生真实姓名。
- AI 与规则分析仅用于辅助发现学习线索，不能替代教师评价、考试结论或升学决策。

## 第一步：启动系统

打开“终端”，运行：

```bash
cd /Users/mac/Documents/教育智能体
make web
```

保持终端窗口开启，然后在浏览器访问：

`http://127.0.0.1:8765`

看到“启智知踪”家长端首页，即表示启动成功。

## 第二步：手动录入第一道题

1. 在首页找到“手动录题”。
2. 学生编号填写 `s001`。
3. 选择题目对应的年级。
4. 填写题干、标准答案和学生作答。
5. 提交后查看页面提示。

系统会出现以下两种结果之一：

- **分析完成**：题目已匹配到知识点，并生成学习证据。
- **进入待复核**：题目未匹配、存在歧义或置信度不足，需要家长确认后才会更新掌握度。

> [!warning] 不要强行归类
> 如果题目超出当前小学二至三年级数学范围，进入待复核是正常的安全保护，不代表系统故障。

## 第三步：查看家长报告

返回首页，点击“查看家长报告”，选择刚才使用的学生编号。报告会展示：

- 已收集题目与有效证据数量
- 当前知识点掌握情况
- 需要优先关注的知识短板
- 最近变化与建议复习任务

如果报告暂时为空，请先确认至少有一道题显示“分析完成”或已完成人工复核。

## 使用试卷照片

1. 在首页选择图片上传入口。
2. 上传清晰的 PNG、JPG、WEBP 或 TIFF 图片，单张不超过 15MB。
3. 等待本地 OCR 识别。
4. 在待确认区核对并修正题干、标准答案和学生作答。
5. 确认无误后提交分析。

> [!important] 必须人工确认
> OCR 结果确认前不会写入学习证据，也不会更新知识掌握度。首次测试建议上传只包含一道题的清晰图片；当前版本不支持整张试卷自动切题。

详细说明见 [[真实OCR与人工确认说明]]。

## 处理待复核题目

进入待复核区后，可以：

- 选择正确的已发布知识点，并确认学生作答正确或错误。
- 对无需处理的任务选择关闭或放弃。
- 无法判断时暂不确认，避免错误数据影响报告。

人工确认会保留审计记录。当前没有合适知识点时，不要为了清空队列而随意选择。

## 数据管理与备份

家长端可查看健康摘要，并对单个学生执行数据导出或二次确认删除。需要完整备份时，在终端运行：

```bash
cd /Users/mac/Documents/教育智能体
make health
make backup
```

具体操作与恢复方法见 [[数据导出删除与备份恢复]]。

## 常见问题

### 浏览器打开后为空或无法访问

确认终端中的服务仍在运行。重新执行 `make web`；如果 8765 端口被占用，可运行：

```bash
python3 -m edu_tracker web --port 8766
```

然后访问 `http://127.0.0.1:8766`。

### 图片识别失败

优先使用光线均匀、文字清晰、画面端正且只包含一道题的图片。复杂公式、模糊手写体和整卷切分仍需人工处理。

### 录题后掌握度没有变化

常见原因包括：没有填写完整答案、题目未匹配、出现多个候选知识点、OCR 尚未确认或分析置信度不足。请到待复核区处理。

### 报告中的结论是否可以直接作为学习评价

不可以。报告仅用于辅助家长发现复习线索，详见 [[AI分析边界说明]]。
