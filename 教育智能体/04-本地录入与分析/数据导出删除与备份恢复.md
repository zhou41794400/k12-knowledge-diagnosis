# 数据导出删除与备份恢复

## 健康检查

```bash
python3 -m edu_tracker health
```

输出数据库版本、题目数、当前掌握状态数、待处理复核数和 outbox 积压数。

## 导出单个学生

```bash
python3 -m edu_tracker data-export --student-id s001
```

导出包保存到项目根目录 `exports/`，包含题目、证据、掌握度、导入、审计、复核和学生相关图片。

## 删除单个学生

```bash
python3 -m edu_tracker data-delete --student-id s001 --confirm s001
```

`--confirm` 必须与学生编号完全一致。删除范围包括 SQLite、JSONL、复核任务、待导出队列、学生报告、题目详情和位于本地日志目录中的图片。

> [!warning]
> 删除不可逆。需保留副本时，必须先导出或创建备份。

## 创建完整备份

```bash
make backup
```

备份保存到 `backups/`，不进入 Git。

## 恢复演练

```bash
python3 -m edu_tracker restore \
  --backup-path /path/to/备份.zip \
  --target /path/to/empty-restore-directory
```

恢复命令只解压到指定目录，不直接覆盖当前 Vault，以避免误操作。

## 验收结果

- 学生导出包可读取并仅包含目标学生数据。
- 删除目标学生后，其他学生数据保持不变。
- 备份可恢复到新目录并通过内容校验。
- 备份恢复包含路径穿越检查。
