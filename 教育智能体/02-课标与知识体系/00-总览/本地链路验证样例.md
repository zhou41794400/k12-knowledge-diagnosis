# 本地链路验证样例

## 样例目标

验证一张试卷照片或一条手动录题能否完整走通本地链路。

## 样例流程

1. 录入一张二年级数学图片或一条八年级英语手动题。
2. 生成 `QuestionRecord`。
3. 产生 `EvidenceEvent`。
4. 更新 `MasteryState`。
5. 写入 `AuditEvent`。
6. 回写到 Obsidian。

## 验证标准

- 有明确的中文展示结果。
- 有可追溯的知识点编码。
- 有复核分支。
- 有审计留痕。
