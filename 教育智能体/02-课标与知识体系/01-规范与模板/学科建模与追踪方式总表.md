# 学科建模与追踪方式总表

| 学科 | 主建模重心 | 推荐追踪方式 | 当前说明 |
| --- | --- | --- | --- |
| 语文 | 字词、阅读、写作、文言、表达 | MIXED | 离散技能可 BKT，综合表达用规则 |
| 数学 | 概念、运算、推理、应用 | BKT | MVP 中最完整的 BKT 学科 |
| 英语 | 词汇、语法、阅读、写作、听说 | MIXED | 词汇语法偏 BKT，综合能力偏规则 |
| 物理 | 概念理解、公式应用、实验 | MIXED | 计算和判断题可量化，实验解释需规则 |
| 化学 | 概念、符号、实验、推断 | MIXED | 方程式与概念题可结构化 |
| 生物学 | 概念、图表、实验分析 | RULE | 首批更适合规则与层级追踪 |
| 道德与法治 | 概念理解、情境判断 | RULE | 主观表达比例高 |
| 历史 | 时序、因果、史料解读 | RULE | 更适合证据型规则追踪 |
| 地理 | 区域、图表、综合分析 | MIXED | 图表题可结构化，综合题偏规则 |
| 科学 | 基础概念、实验观察 | MIXED | 小学科学先做轻量追踪 |
| 信息科技 | 概念、操作、流程 | MIXED | 操作类需单独证据模板 |
| 体育与健康 | 行为、知识、习惯 | RULE | 更偏行为与过程性记录 |
| 艺术 | 鉴赏、表达、创作 | RULE | 更适合成长档案与规则追踪 |
| 劳动 | 过程、习惯、任务完成 | RULE | 更适合任务型证据 |

## 当前原则

- 数学优先走完整 BKT。
- 语文、英语、理科采用 `MIXED`，避免强行统一。
- 高主观性学科优先用 `RULE`，后续再细化可量化子技能。
